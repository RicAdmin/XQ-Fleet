# Book a Langkawi Car Rental (XQCar)

Use this skill when an agent needs to help a user search fleet availability and book a car on XQCar.

## Site

- Home: https://carxq.com/
- Checkout requires pickup/return dates, location, and driver details.

## Workflow

1. Open the homepage and set pickup and return dates plus times.
2. Choose pickup location: Langkawi Airport (LGK Door 3), Kuah Ferry Jetty, or hotel delivery.
3. Browse available vehicles filtered by passenger and luggage needs.
4. Select a car to view pricing, inclusions, and add-ons.
5. Complete checkout with driver name, licence details, contact email, and phone.
6. Pay online via supported methods (FPX, cards) or follow on-screen instructions.

## Constraints

- Minimum driver age 21 with licence held 1+ year.
- Service area: Langkawi Island, Kedah, Malaysia only.
- Do not submit bookings without explicit user confirmation of dates, car, and price.
